# Data

This folder is intentionally empty in version control (see `.gitignore`).

## Download instructions

### Zenodo UAV Thermal PV Dataset
DOI: 10.5281/zenodo.16420123
Download directly from the Zenodo record page or via the Zenodo API, then
place contents under `data/raw/zenodo/`.

### PVF-10 (pending license confirmation)
Repo: github.com/wangbobby1026/PVF-Dataset
Do not download/use until license is confirmed -- see `DATA_LICENSES.md`.

After downloading, run `scripts/download_data.sh` or follow
`notebooks/01_data_exploration.ipynb` to verify and preprocess.
